# 🛒 Retail Sales Analysis using SQL

## 📌 Project Overview

This project analyzes retail sales data using SQL to understand 
customer behavior, product performance, and revenue trends.

The goal of this project is to extract meaningful business insights 
that can help in data-driven decision making.


## 📊 Dataset Description

The database contains the following tables:

- **customers** – Customer details
- **orders** – Order information
- **order_details** – Product-level order data
- **products** – Product categories and pricing

## 🛠 Tools & Skills Used

- MySQL
- SQL Joins
- Aggregate Functions (SUM, COUNT)
- GROUP BY & ORDER BY
- Window Functions (RANK)


## 🔎 Key Analysis Performed

1. Total Revenue Generated
2. Revenue by Product Category
3. Top Customers by Total Spending
4. Customer Ranking using Window Functions


## 📊 Sample Insights

- Total Revenue: ₹155,000
- Top Category: Electronics (₹140,000)
- Top Customer: Amit Sharma (₹90,000)



## ▶️ How to Run the Project

1. Create the database using `schema.sql`
2. Insert sample data using `data.sql`
3. Run analysis queries using `analysis_queries.sql`
